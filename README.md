# NOVA AI — Creative Studio Website

A cinematic, dark, editorial portfolio for **NOVA AI** — an AI-powered creative advertising studio.
Designed as a premium international studio site: oversized typography, numbered editorial sections,
scroll-driven motion, full-screen navigation and dedicated case-study pages.

Built with **zero dependencies** — plain HTML, CSS and vanilla JS. No build step required to run.

---

## Quick start

**Option 1 — just open it**

Double-click `index.html`. (Google Fonts need internet; everything else works offline.)

**Option 2 — local server (recommended for testing videos/fonts)**

```powershell
python -m http.server 8756
# open http://localhost:8756/
```

```
├─ work/<slug>/index.html      # Generated case-study pages (one per project)

│  ├─ css/main.css             # Full design system
│  ├─ js/main.js               # Motion, nav, reveals, video triggers

│  ├─ img/                     # Posters, keyframes, transparent logo, favicons
│  └─ data/projects.json       # ★ The "CMS" — all project content lives here
├─ projects/                   # Your original source videos (input)
├─ logo/                       # Your original logo (input)
└─ tools/
   ├─ build.py                 # Generates work/* pages + homepage reel from projects.json
   ├─ optimize_media.py        # Re-encodes videos, extracts posters & keyframes
   ├─ build_logo.py            # Removes the black logo background, makes favicons
   └─ check_refs.py            # Verifies every asset reference resolves
```

## Adding a project (the CMS workflow)

1. **Add content** — open `assets/data/projects.json` and add an object to `projects`:

   ```json
   {
     "slug": "my-project",
     "title": "My Project",
     "client": "Client Name",
     "category": "Beverage",
     "discipline": "AI Product Commercial",
     "year": "2026",
     "featured": false,
     "services": ["Creative Direction", "Compositing"],
     "description": "Short line used on the homepage reel.",
     "overview": "Case study intro…",
     "creativeDirection": "…",
     "visualApproach": "…",
     "production": "…",
     "finalResult": "…",
     "role": "Full production"
   }
   ```

   > `featured: true` promotes a project into the large homepage hero block (V7 uses it).
   > Related projects are picked automatically (the next three in the list).

2. **Add a video** — drop the source `.mp4` into `projects/` and map it in
   `tools/optimize_media.py` (`MAPPING`), then run it once:

   ```powershell
   python tools/optimize_media.py
   ```

   This creates the optimized web video + poster + 3 gallery keyframes in `assets/`.

3. **Regenerate pages**:

   ```powershell
   python tools/build.py
   ```

4. Done — the new project appears in the homepage reel and at `work/<slug>/index.html`.

## Editing contact & social links

Update once in `assets/data/projects.json` → `contact`. It feeds:
- Contact section + footer of every page (generated by `tools/build.py`).

The **homepage CTA / hero links** point to `mailto:`/`wa.me` links that are also generated
from the same file. To change anything homepage-side, regenerate with `python tools/build.py`.

## Design system notes

- **Type**: Archivo (display) · Inter (body) · JetBrains Mono (labels)
- **Palette**: near-black `#0a0a09`, warm white `#ece9e2`, single vermilion accent `#ff4a21`
- **Motion**: generous cubic-bezier ease, mask-line reveals, scroll parallax,
  sticky showcase and magnetic CTAs. Respects `prefers-reduced-motion`.

## Deploy

It's a static site — drop the folder on Netlify, Vercel, Cloudflare Pages, GitHub Pages
or any web host. Before going live:

- Update `assets/img/og-image` references and the `og:url` in `index.html` if you
  want a canonical domain (currently a placeholder).
- If you rename the studio site root, the paths are all relative — it works from any subfolder.

## Security

The site is **100% static — there is no backend**: no server-side code, no database,
no form processor, no admin panel. The contact form opens WhatsApp/e-mail directly
from the visitor's browser, so there is no server-side surface to attack.

What is shipped to harden it:

- **`_headers`** — security headers for **Netlify / Cloudflare Pages**
  (same file format, works on both). Sets:
  - `Content-Security-Policy` (locked to the site's real needs: own scripts/media,
    Google Fonts only, no frames, no plugins, HSTS upgrade)
  - `X-Content-Type-Options: nosniff` · `X-Frame-Options: DENY`
  - `Referrer-Policy` · `Permissions-Policy` (blocks camera/mic/geo/tracking topics)
  - `Cross-Origin-Opener-Policy: same-origin`
  - `Strict-Transport-Security` (HTTPS only)
- **`vercel.json`** — identical headers for **Vercel** deploys.
- **`.htaccess`** — same headers for classic **Apache** hosts, plus
  `Options -Indexes` and denial of dotfiles.
- **`robots.txt`** — allows all crawlers.
- **`.well-known/security.txt`** — security contact for reporters.

Checks that already pass in the codebase:

- No `eval`, `innerHTML`, `document.write`, `blob:` or dynamic HTML anywhere.
- No inline third-party scripts — only the local `main.js` and a static JSON-LD block.
- Every external link is `rel="noopener"`; social links are clean handle URLs (no tokens).
- Mixed-content scan: zero `http://` references.
- Contact details are public by design (e-mail + WhatsApp) — never commit passwords,
  API keys or session tokens.

To verify headers after deploying:

```bash
curl -sI https://your-domain/ | findstr /i "content-security x-frame x-content referrer strict-transport"
```

## Performance

- Videos are re-encoded to H.264, ~720p, `+faststart`, no audio (≈2 MB each).
- Videos use `preload="metadata"` / `preload="none"` and only play on scroll-into-view
  or hover — never all at once.
- Images are JPEG posters/keyframes extracted straight from the films.
- No animation/framework libraries — everything is rAF + IntersectionObserver.
